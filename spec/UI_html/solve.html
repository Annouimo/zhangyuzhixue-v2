在三角形 ABC 中，角 A、B、C 的对边分别是 a、b、c，且满足 a² + b² - c² = ab。

(1) 求 cos C 的值；

(2) 若 c = 3，求 a + b 的最大值。

由题意可得 a² + b² - c² = ab，由余弦定理 cos C = (a² + b² - c²) / (2ab) = ab / (2ab) = 1/2，故 C = 60°。

⏳ 还剩 10 秒可查看
正确答案
60°

由余弦定理 cos C = (a² + b² - c²) / (2ab) = ab / (2ab) = 1/2，故 C = 60°。

解法：
🔒 请先完成上一问
第 1 步 · 代值计算
三角恒等变形

由余弦定理 cos C = (a² + b² - c²) / (2ab)，
代入 a² + b² - c² = ab，
得 cos C = ab / (2ab) = 1/2，故 C = 60°。

第 1 步 · 建系
向量点积

以 C 为原点，CA 为 x 轴正方向建立坐标系。
设 CA = b，CB = a，则 C(0,0)，A(b,0)，B(a cos C, a sin C)。
由 cos C = 1/2 得 sin C = √3/2，
AB² = (b - a/2)² + (0 - a·√3/2)² = a² + b² - ab。
已知 a² + b² - c² = ab，c = AB，代入得 a² + b² - ab = ab，
即 a² + b² - 2ab = 0，... → cos C = 1/2。

第 1 步 · 代入
正弦定理 化简

由正弦定理：a = 2R sin A，b = 2R sin B，c = 2R sin C。
c = 3，C = 60°，sin C = √3/2，得 2R = 3 / (√3/2) = 2√3。
所以 a + b = 2R (sin A + sin B) = 2√3 (sin A + sin B)。

第 2 步 · 结论
辅助角公式

A + B = 120°，所以 B = 120° - A。
sin A + sin B = sin A + sin(120° - A)
= sin A + sin 120° cos A - cos 120° sin A
= sin A + (√3/2) cos A + (1/2) sin A
= (3/2) sin A + (√3/2) cos A
= √3 sin(A + 30°)。
所以 a + b = 2√3 × √3 sin(A + 30°) = 6 sin(A + 30°)。
当 A = 60° 时，a + b 取最大值 6。
