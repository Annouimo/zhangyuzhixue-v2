(1) 求 cos C 的值 · 余弦定理法 · 第 1 步 · 代值计算

相关概念：三角恒等变形

在三角形 ABC 中，角 A、B、C 的对边分别是 a、b、c，且满足 a² + b² - c² = ab。

由余弦定理求 cos C。

📖 三角恒等变形 📖 余弦定理
⏳ 还剩 5 秒可查看

由余弦定理 cos C = (a² + b² - c²) / (2ab)，

代入 a² + b² - c² = ab，

得 cos C = ab / (2ab) = 1/2，故 C = 60°。
