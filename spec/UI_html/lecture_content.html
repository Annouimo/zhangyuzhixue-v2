第 2 讲 导数的几何意义

一、导数的几何意义

函数 y = f(x) 在点 x₀ 处的导数 f'(x₀) 的几何意义是：曲线 y = f(x) 在点 (x₀, f(x₀)) 处的切线的斜率。

切线方程为：$y - f(x_0) = f'(x_0)(x - x_0)$

典型例题

例 1 求曲线 y = x³ 在点 (1, 1) 处的切线方程。

解：y' = 3x²，所以 k = f'(1) = 3。
切线方程为 y - 1 = 3(x - 1)，即 y = 3x - 2。

例 2 已知曲线 y = x² + 1，求过点 (1, 2) 的切线方程。

解：y' = 2x，k = f'(1) = 2，切线方程为 y - 2 = 2(x - 1)，即 y = 2x。

二、常见题型——求切点坐标

已知切线斜率（或切线方程），求切点坐标是导数几何意义的逆向应用。

例 3 曲线 y = x³ + x - 2 在点 P 处的切线平行于直线 y = 4x - 1，求 P 点坐标。

解：y' = 3x² + 1，由 k = 4 得 3x² + 1 = 4，解得 x = ±1。
代入得 P(1, 0) 或 P(-1, -4)。

例 4 求曲线 y = sin x 在点 (π/3, √3/2) 处的切线方程。

解：y' = cos x，k = cos(π/3) = 1/2，切线方程为 y - √3/2 = (1/2)(x - π/3)。

三、含参切线问题

当曲线方程中含有参数时，需要通过切线条件建立方程求解参数。

例 5 若曲线 y = ax² + bx 在点 (1, 1) 处的切线方程为 y = 3x - 2，求 a, b。

解：由过点 (1, 1) 得 a + b = 1。
y' = 2ax + b，k = 2a + b = 3。
联立得 a = 2, b = -1。

例 6 曲线 y = x³ + ax 与直线 y = 2x 相切，求 a 的值。

解：设切点 (t, t³ + at)，则 k = 3t² + a = 2，且 t³ + at = 2t。
消去 a 得 t³ = 0，t = 0，代入得 a = 2。

四、公切线问题

公切线是指同时与两条曲线相切的直线。解题关键是设出切点，利用斜率相等且切线重合建立方程。

例 7 求曲线 C₁: y = x² 与 C₂: y = -x² + 4x - 4 的公切线方程。

解：设 C₁ 上切点为 (a, a²)，则切线为 y - a² = 2a(x - a)。
与 C₂ 联立判别式 Δ = 0，解得 a = 1。
公切线为 y = 2x - 1。

小结：公切线问题的一般步骤：
① 分别设两个切点；
② 写出两条切线方程；
③ 令两切线为同一直线（斜率相等、截距相等）；
④ 解方程组求得切点坐标。

五、综合练习

请独立完成以下练习，检验本讲掌握情况。

练习 1 求曲线 y = ln x 在点 (1, 0) 处的切线方程。
练习 2 求曲线 y = eˣ 过原点的切线方程。
练习 3 已知函数 f(x) = x³ - 3x，求过点 (2, 2) 的切线方程。

参考答案
1. y = x - 1
2. y = e·x（提示：设切点 (t, eᵗ)，联立过原点条件）
3. y = 9x - 16 或 y = 2

六、课堂小结

导数的几何意义是高考的高频考点，核心是"求切线三步法"。

求切线三步法：

  1. 求导：f'(x) 即为切线斜率函数；
  2. 代点：将切点横坐标代入得斜率 k = f'(x₀)；
  3. 写方程：点斜式 y - f(x₀) = k(x - x₀)。

注意事项

  • 区分"在点 P 处"（P 为切点）与"过点 P"（P 不一定为切点）；
  • 含参问题注意联立条件时不要遗漏切点在曲线上的条件；
  • 公切线问题注意两条曲线可能对应不同切点。
