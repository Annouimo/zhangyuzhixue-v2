# 旧教学功能归档与恢复说明 V1.0

> 归档时间：2026-07-27  
> 归档基线：`52dee55361c9ae785fd5c522528420b8ddbe80f0`  
> 基线分支：`master`  
> 状态：删除前归档，尚未开始删除业务代码

## 1. 归档目的

项目将从“课程、班级和教师作业平台”转向“免费讲义、圆明智学公开内容和个性化练习相互连接的高考数学学习工具”。

删除前保留可验证的代码、数据和架构说明，供未来参考。归档不表示未来应当原样恢复旧功能。

## 2. 归档范围

### 2.1 学生端

- 作业列表、作业详情和作业路由。
- `AssignmentRepository`、`AssignmentDao` 及待办作业 API。
- 作业缓存、可访问课程 ID 和待办数量首选项。
- 本地内容数据库中的作业及作业-题目关联表。
- 学习记录中的历史 `assignment_id` 来源字段。

### 2.2 讲义

- 讲义列表、章节目录、Markdown 渲染、分页和逐段展开功能保留。
- 旧 `Course` 模型同时承担课程业务和讲义分组，删除时不能直接移除。
- 预期将 `Course` 转为 `LectureSeries`，将 `Document` 转为 `LectureDocument`。
- 讲义将取消班级/课程授权，作为软件内的免费内容。

### 2.3 教师 Flutter 端

- 题库浏览、题目详情和预览。
- 讲义列表、章节和讲义内容。
- 题库/课程数据包更新。
- 设置、日志导出和协议入口。

教师端的题库筛选和只读浏览交互可供学生端题库浏览功能参考，不建议整个客户端回滚或直接复制。

### 2.4 教师 Web 与教师 API

- 教师登录、班级、学生列表和学生详情。
- 作业创建、发布、修改、撤销、催交和分班完成情况。
- `/api/v1/teacher/` 下的教师专用路由。

### 2.5 服务端数据模型

- `Course`
- `ClassGroup`
- `ClassCourse`
- `Document`（保留并迁移为讲义模型）
- `Assignment`
- `AssignmentQuestion`
- `ClassCourseAssignment`
- `StudentSubmission.assignment`（先保留历史数据，后续解除关联）

## 3. 现有依赖关系

```text
ClassGroup
  └─ ClassCourse ── Course ── Document
          │             └─ Assignment
          └─ ClassCourseAssignment ── Assignment
                                           └─ AssignmentQuestion ── BaseQuestion

StudentSubmission
  └─ Assignment (nullable, historical source)
```

学生端作业流程同时依赖讲义数据库、题库、用户学习记录和服务端 API，必须先停止写入，再分阶段移除。

## 5. 预期删除顺序

1. 冻结新课程授权和新作业发布。
2. 取消讲义的班级/课程权限过滤。
3. 将教师端有价值的题库浏览能力合入学生端。
4. 删除学生端作业页面、路由、缓存、Repository 和 DAO。
5. 停止发布教师 Flutter 和教师 Web。
6. 删除教师 API、作业 API 和权限分支。
7. 迁移 `Course/Document` 为讲义系列/讲义文档。
8. 在生产数据库副本上验证数据迁移。
9. 最后才物理删除作业、班级课程关联和废弃字段。

## 6. 未来恢复指南

查看归档文件：

```powershell
git show archive/legacy-teaching-platform-v1:<path>
```

将单个文件提取到当前工作树：

```powershell
git restore --source archive/legacy-teaching-platform-v1 -- <path>
```

比较归档与当前实现：

```powershell
git diff archive/legacy-teaching-platform-v1..HEAD -- teacher_app server/courses flutter_app/lib/pages/homework
```

从 Git bundle 恢复归档引用：

```powershell
git bundle verify <bundle-path>
git fetch <bundle-path> "refs/tags/archive/legacy-teaching-platform-v1:refs/tags/archive/legacy-teaching-platform-v1"
```

## 7. 不应原样恢复的设计

- 不再将讲义内容分组和课程售卖/授权绑定在同一模型。
- 不再为题库浏览和讲义浏览维护独立 Flutter 客户端。
- 不将教师作业、人工咨询和个性化服务复用为同一业务模型。
- 不直接合并整个归档分支恢复功能；应先根据当前领域模型选择性提取代码和测试。
