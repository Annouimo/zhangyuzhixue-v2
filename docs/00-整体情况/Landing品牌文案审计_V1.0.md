# Landing 品牌文案审计 V1.0

> 范围：`landing/` 下公开品牌页面、公共页头页脚与微信咨询组件  
> 不纳入：教师后台、隐私政策、服务条款和内部页面的业务正文  
> 状态：本文件建立替换清单；页面修改在后续阶段实施

## 1. 结论

现有 Landing 信息完整、边界总体谨慎，但仍以“免费软件 + 付费课程”的产品分类为中心，与新版海报“先接触、先了解、再选择服务”的品牌主线不一致。

主要问题：

1. “付费教学服务”在首页首屏、FAQ、课程页和公共页脚重复出现，抢占第一印象。
2. “第一节课免费试听”没有成为课程链路的统一主 CTA。
3. 团队多对一个性化学习方案尚未进入官网内容体系。
4. 团队页仍按职务和职能组织，与新版“姓名 + 履历”规则冲突。
5. 首页团队文案强调开发、设计和测试职能，不能有效建立家长关心的专业可信度。
6. “不提供竞赛课程”出现频率偏高；边界应保留，但不应反复打断正向叙事。

## 4. P2：精简或降级

“不提供竞赛课程”仅重点保留在关于页项目边界、团队页履历说明、创新题课程解释和 FAQ；首页团队区不再重复。

“软件测试员”“美术总助”“技术与运营负责人”等内部职能不作为主要品牌背书。项目支持成员可以公开，但主层级优先展示可核实履历和高考数学相关专业背景。

减少“协同发力”“协同发展”“持续迭代”“深度教学服务”等辨识度较低的泛化表达，改为用户能够直接理解的价值和行动。

## 5. 页面改写边界

- **首页**：保留品牌定义、软件截图、三门课程、FAQ 和联系方式；重写首屏辅助文案、免费服务、理念、团队背书和课程 CTA；不承担详细收费说明，但不得暗示完整课程永久免费。
- **软件页**：保留“当前免费开放”及范围说明；软件能力必须与正式版本一致；三端下载入口和系统要求上线前实测。
- **课程页**：保留课程结构和试听说明；删除宣传位置的付费硬标签；费用保持透明，放入 FAQ、咨询说明或价格区域；“开放报名”逐期确认。
- **团队页**：按新版顺序重建；移除职务、负责人和职能标签；只保留核实履历；支持成员合并为一组。
- **关于页**：用于说明品牌理念、教育主张、适用对象和项目边界，避免重复首页产品清单。
- **公共组件**：更新页脚总述与 CTA；微信弹窗统一说明可咨询软件、课程、试听和社群。

## 6. 法律与诚信边界

- 避免“付费教学服务”硬标签不等于隐藏收费事实。
- 隐私政策、服务条款和交易前说明不随宣传语机械替换。
- “免费”必须明确对应软件、社群、讲座或第一节试听课，不能暗示完整系统课程永久免费。
- “个性化”“智能”“学习分析”等能力必须与当前上线功能一致。
- “高端私人定制”“团队多对一”在服务机制核验前不能直接上线。
- 团队履历应取得成员本人对公开展示和措辞的确认。
