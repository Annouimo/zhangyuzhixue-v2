# 🗂 本地数据库结构设计（drift）

> 本文档定义 Flutter 客户端 SQLite 数据库的完整 Schema，供 drift DAO 代码生成和 Repository 层实现使用。
>
> **原则**：尽可能与服务器 DB 保持一致（镜像），仅在必要时做本地特有调整（双库拆分、chapter 本地生成、fill_ext/solution_ext 不建）。所有本地只有的表（chapter、sync_queue）在文档中标注。

---

## 一、数据库划分

```
本地 SQLite
│
├── assets.db（预置只读）
│   生命周期：随 App 版本整体替换
│   路径：首次启动从 assets/ 复制到 getApplicationDocumentsDirectory()
│   └─ 版本检查：GET /api/sync/question-bank-version
│
└── user.db（用户读写）
    生命周期：跨版本保留，登出清空（可选）
    路径：getApplicationDocumentsDirectory()
```

**为什么拆两个库？**
- assets.db 随发版替换（App 更新时覆盖），user.db 跨版本留存
- 合在一个库中，替换 assets 表时容易误清用户数据
- Drift 支持同时挂两个 `DriftDatabase` 实例，Repository 按需读

## 二、Assets 预置库（14 张表）

所有表均**只读**。数据由构建脚本从服务器 Django DB 导出 → 转换 → 生成 `.db` 文件，随 App 打包。

### 2.1 题库核心

#### a1. `question`（题目主表）

与服务器 `BaseQuestion` 直接对应。`images` 是双向对齐的新字段（服务器也需添加）。选择题选项、概念标签等不在本题存储，通过 `choice_ext` / `question_concept_tag` 分别关联。

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `id` | INTEGER | PK | 与服务器 BaseQuestion.id 一致 |
| `year` | INTEGER | | |
| `exam_type` | TEXT | | 考试类型 |
| `region` | TEXT | | 地区 |
| `number` | TEXT | | 题号 |
| `question_type` | TEXT | NOT NULL | 选择/填空/解答 |
| `difficulty` | REAL | | 0-10 |
| `calculation` | REAL | | 0-10 |
| `stem` | TEXT | NOT NULL | 纯 Markdown，**不含 img 标签** |
| `images` | TEXT | | **JSON list**：`["一模/2024/海淀/q17.webp"]`<br>必随 stem 一起读，不会单独 WHERE 过滤 |
| `default_score` | REAL | | 参考分值 |

#### a2. `choice_ext`（选择题扩展表）

## 四、跨库关联说明

```
assets.db                          user.db
┌────────────────┐               ┌──────────────────────┐
│ question       │◄──────────────│ submission_detail    │
│ .id            │  question_id  │ .question_id         │
├────────────────┤               ├──────────────────────┤
│ sub_question   │◄──────────────│ step_feedback        │
│ .question_id   │  (indirect)   │ .sub_question_index  │
│ .id            │               │ .method_id           │
├────────────────┤               ├──────────────────────┤
│ solution_method│               │ card_feedback        │
│ .id            │               │ .card_title          │
├────────────────┤               ├──────────────────────┤
│ concept_tag    │               │ student_achievement  │
│ .name          │               │ .achievement_code    │
├────────────────┤               └──────────────────────┘
│ achievement_def│ ◄────────────────
│ .code          │   code
└────────────────┘
```

**不声明 SQL 级外键**（SQLite 不支持跨文件 FK），由 Repository 代码保证引用一致性。跨库写入前做 Dart 校验（如查 question.id 存在再写 submission_detail）。
