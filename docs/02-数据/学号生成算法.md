## 6.1 学号生成算法（LCG）

学号由两部分拼接：**前缀** + **LCG 数字串**。

### 前缀（可配置）

存储在 `SystemConfig` 表中，key=`student_id_template`，当前默认值 `202610{lcg}`。

管理员可在 Django Admin → System Config 中修改。修改后仅影响新创建的学生，不影响已有学生。

### LCG 数字串（不可逆混淆）

采用线性同余变换（Linear Congruential Generator），将数据库自增 `id` 映射为 5 位数字串。

**正向编码：** `lcg = ((uid - 1) × A + C) % M`

**反向解码：** `uid = ((lcg - C) × INV_A) % M + 1`

**参数（一旦确定严禁修改）：**

| 参数 | 值 | 说明 |
|:--|:--|:--|
| `A`（乘数） | 71237 | 与 100000 互质 |
| `C`（偏移量） | 58417 | 随机偏移 |
| `M`（模数） | 100000 | 即 5 位数字 |
| `INV_A`（逆元） | 48173 | A 在模 M 下的乘法逆元 |

**验证数据**（1~99999 全量验证无碰撞）：

| uid | LCG | 完整学号 |
|:--|:--|:--|
| 1 | 58417 | 20261058417 |
| 2 | 29654 | 20261029654 |
| 3 | 00891 | 20261000891 |
| 100 | 10880 | 20261010880 |

### 关键原则

- 学号由服务端 `Student.save()` 首次创建时自动生成
- 创建后管理员可在 Admin 中手动修改（如加 `VIP` 前缀）
- `student_id` 有 `unique` 约束，不允许重复
- LCG 是**混淆**而非加密，能防普通用户猜测规模，不防逆向工程
