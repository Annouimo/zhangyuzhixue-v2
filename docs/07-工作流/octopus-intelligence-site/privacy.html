一、适用范围

本政策用于说明章鱼智学静态官方网站及相关软件在提供服务过程中如何处理用户信息。

本静态官网不设置在线注册、登录、报名、支付或表单，不主动收集访问者提交的个人信息。网站服务器仍可能生成必要的访问日志，具体以实际部署配置为准。

官网可能提供 Android、iOS 与 Windows 下载链接。访问应用商店或下载平台后，相关平台将依据其自身规则处理信息。

软件内的账号、学习记录、设备权限与第三方 SDK 等信息处理规则，应在正式政策中单独、完整说明。

项目面向学生用户，正式政策应说明监护人同意、未成年人信息保护、账号注销和投诉处理方式。
