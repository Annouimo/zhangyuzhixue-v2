# UI 重构第二批说明

本批建立在第一批之上。学生端首页和推荐页完成重构。

## 学生首页

- 首页重构为"今日学习仪表盘"。
- Hero 区域：今日练习状态徽标 + 随机欢迎语 + 待办/自由状态描述 + 快速练习按钮（手机全宽/宽屏内联）。
- 四格概览：待办作业数、今日练习量、正确率、当前等级。
- 统一学习资源区：作业列表 + 讲义入口卡片。
- 签到卡片：连续天数 / 签到按钮 / 七日进度条。
- 每日任务：3 项今日待完成任务，完成自动发放积分奖励。
- 等级积分：当前等级进度条 + 今日获得积分。
- 手机单列 / 宽屏双栏布局（≥600dp）。
- 同步状态提示 + 新手引导。

## 推荐页

- 说明区 + 题目数量概览。
- 智能推荐 / 偏好推荐模式切换。
- 偏好选择器（使用统一表单样式重构）。
- 推荐题卡：题型、难度、状态、推荐原因、主行动按钮。
- 空状态 + 下拉刷新（短列表也可刷新）。
