# winnav 按钮坐标表

## 用法

`winnav_click_at(x=<锚点x>, y=<锚点y>, dx=<dx>, dy=<dy>)`

实际点击位置 = 锚点(`x_pct × client_w`, `y_pct × client_h`) + (`dx`, `dy`)

`dx`/`dy` 是客户区像素偏移，不随窗口 resize 变化。
校准新按钮：`winnav_mouse_pos(x_pct, y_pct)` → 记录 `offset_px` → 填入下表。

## 通用锚点

| 锚点 | `(x_pct, y_pct)` | 适用场景 |
|------|:-----------------:|---------|
| 左上角 | (0, 0) | AppBar 返回按钮、Dialog 关闭按钮 |
| 左下角 | (0, 1.0) | 底部条左端按钮 |
| 右下角 | (1.0, 1.0) | 底部条右端按钮 |
| 右上角 | (1.0, 0) | 页面右上角操作按钮 |

## 图标按钮坐标

> 仅收录 OCR 不可见且无文字可点的 Icon。行内文字（"待办作业""讲义"等）本身在 `InkWell` 内可点击，不必点右侧 `>`。AppBar `←` 用 `y_range` 区分。

| 按钮 | 页面 | 锚点 | dx | dy | 校准状态 |
|------|------|------|:--:|:--:|:--------:|
| 翻页栏 ◀ | lecture_content | (0, 1.0) 左下角 | 57 | -66 | ✅ 实测校准 |
| 翻页栏 ▶ | lecture_content | (1.0, 1.0) 右下角 | -57 | -66 | ✅ 对称推算（未实测） |

## 校准方法

```python
# 1. 打开讲义正文页（确保看到底部翻页栏）
# 2. 把鼠标移到 ◀ 按钮中心
winnav_mouse_pos(x_pct=0, y_pct=1.0)   # 锚点左下角
# 3. 记录返回的 offset_px，填入上表
# 4. 验证：
winnav_click_at(x=0, y=1.0, dx=<偏移>, dy=<偏移>)
```
