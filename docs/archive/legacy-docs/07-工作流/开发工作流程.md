# 章鱼智学 · 开发工作流程

> 本文档定义从设计稿到 Flutter 代码的开发流程，以及修改 HTML 后的同步更新规则。

---

## 一、HTML 原型 → Flutter 代码

```
1. 设计阶段
   UI_设计草稿.canvas（手绘草图→已归档）
        │
        ▼
   UI_html/*.html（可交互原型）
        │
        ▼
   评审定稿
        │
        ▼
2. 开发阶段
   Flutter UI Widget → 对照 HTML 布局
   Repository 层     → 对照 data-db 标记 + Repository/*.dart
   SQLite (drift)    → 对照 数据库结构设计.md
        │
        ▼
3. 数据对接
   把 repository.dart 中 throw UnimplementedError
   替换为 drift DAO 调用 + API 调用
```

## 二、修改 HTML 后的同步流程

修改 HTML 中的 `data-db` 路径后，需要同步更新：

```
1. 修改的 HTML 文件            ← data-db 路径
2. 对应的 repository.dart      ← 模型字段名或方法返回结构
3. 所有 HTML 中相同路径的其他页面 ← 全文搜索确保一致性
```
