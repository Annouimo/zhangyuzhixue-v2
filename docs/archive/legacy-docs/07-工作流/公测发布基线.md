不在源代码尚未冻结时预填。

## 二、发布前阻断项

- [ ] 生产安全配置通过检查
- [ ] 数据库迁移已执行：`python manage.py migrate`
- [ ] 每日匿名化任务已配置：`python manage.py anonymize_deleted_accounts`
- [ ] CI 全部通过
- [ ] 注册协议同意流程可用
- [ ] 修改密码和注销申请可用
- [ ] 自动题库审查无阻断问题
- [ ] Windows 核心流程通过
- [ ] iPhone 真机核心流程通过
- [ ] Android 真机核心流程通过
- [ ] 备份恢复演练通过
- [ ] 部署和回滚步骤已验证
- [ ] 公测人数和邀请码发放受控

> 本版启用了密码哈希令牌校验。升级后旧登录令牌会失效，用户需重新登录一次。
