章鱼智学 · 系统架构

Flutter 本地优先架构 · Django 纯 API 后端 · 离线可做题

核心设计原则

  • • 本地优先：离线可做题，网络仅用于同步/更新
  • • 三库独立：assets / lectures / user 各自 DB 整体替换
  • • Repository 按 UI 需求拼装数据，不暴露表结构
  • • SQLite 三库镜像服务端结构，去范式化只在 JSON 字段

数据流方向

  • • 读：Widget → Repository → DAO → SQLite → 返回拼装
  • • 写：用户操作 → 本地 SQLite（即时）→ sync_queue → 批量推 API
  • • 更新：Server Version API → 弹窗 → .db.gz 下载校验 → 替换
  • • 认证：Login → JWT(SP) → API Client 自动刷新 → 401 重定向

关键技术栈

  • • Flutter 3.x / Dart 3.x / Drift (SQLite ORM)
  • • Django 5 / DRF / djangorestframework-simplejwt
  • • flutter_markdown_plus + flutter_math_fork (LaTeX)
  • • ECS 2C2G + SQLite WAL + Cloudflare Tunnel
