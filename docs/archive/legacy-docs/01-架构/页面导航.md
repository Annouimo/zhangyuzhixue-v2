# 章鱼智学 · 页面导航

> 本文档定义项目所有页面的路由关系和导航结构。

---

## 页面导航关系

```
                    login → register
                        │
              ┌─────────▼─────────┐
              │   MainShell       │
              │ 首页/推荐/组卷/我的 │
              └─────────┬─────────┘
                        │
        ┌───────────────┼───────────────────┐
        ▼               ▼                   ▼
  ┌─────────┐    ┌───────────┐      ┌───────────┐
  │ 首页     │    │ 推荐       │      │ 组卷       │
  └────┬────┘    └───────────┘      └─────┬─────┘
       │                                   │
       ├──→ homework_list                  ├──→ paper_auto
       ├──→ lecture_courses                ├──→ paper_pick
       └──→ ...                            ├──→ paper_history
                                    ┌──────┴──────────┐
                                    │ 作业/讲义/解题等  │
                                    │ 二级页面（无底栏） │
                                    └─────────────────┘
```

所有子页面均无底部导航。CSS `body.has-nav` 控制 padding。

### 一级页（底部导航 Tab）

| 页面 | 路径 | 说明 |
|------|------|------|
| 首页 | `index.html` | 看板：欢迎语+待办作业+讲义入口+签到任务 |
| 推荐 | `recommend.html` | 智能推荐 / 偏好推荐双模式 |
| 组卷 | `exam.html` | 新组卷 + 三个功能入口 |
| 我的 | `profile.html` | 个人信息 + 功能入口列表（分组） |

### 二级页面一览

| 页面 | 路径 | 说明 |
|------|------|------|
| 解题模式（选填） | `solve-choice.html` / `solve-fill.html` | 选择题 / 填空题 独立页面，支持 mode=first|resume|review&attempt_id 参数 |
| 解题模式（解答） | `solve-map.html` / `solve-step.html` | 流程图导航 + 步骤详情（v2 架构），支持 mode=first|resume|review&attempt_id 参数 |
| 评分页 | `solve-rate.html` | 三题型共享：3维×10星 评分，允许修改 |
| 讲义课程 | `lecture_courses.html` → `lecture_chapters.html` → `lecture_content.html` | 三级下钻 |
| 智能组卷 | `paper_auto.html` | 筛选 + 题型 stepper + 难度调优 |
| 自主选题 | `paper_pick.html` | 筛选 + 逐题勾选，底部固定条 |
| 预览（自己） | `paper_quicklook.html` | 公开开关 + 删除 |
| 预览（他人） | `paper_quicklook_other.html` | 点赞 + 收藏 |
| 我的组卷 | `paper_history.html` | 列表 + 公开/私密开关 |
| 发现组卷 | `paper_explore.html` | 4种排序 + 点赞 + 收藏 |
| 我的收藏 | `paper_favorites.html` | 收藏的他人试卷 |
| 快对答案 | `answer_sheet.html` | 答案速览列表 |
| 偏好管理 | `preference_list.html` → `preference_edit.html` | 列表 + 编辑 |
| 首次引导 | `preference_welcome.html` | 注册后无偏好时跳转 |
| 学习统计 | `statistics.html` | 概览 + 4 个图表卡片 |
| 编辑资料 | `profile_edit.html` | 个人资料编辑 |
| 成就 | `achievement.html` | 成就列表 |
| 等级 | `level_detail.html` | 等级进度 |
| 积分流水 | `points.html` | 积分记录 |
| 做题历史 | `question_history.html` | 历史记录 |
| 关于 | `about.html` | 版本信息 |
