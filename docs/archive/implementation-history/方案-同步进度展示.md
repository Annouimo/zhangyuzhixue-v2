## 一、决策汇总

| 项 | 决策 |
|----|------|

## 二、改动清单

### 2.1 SyncManager —— 加 onProgress 回调

```dart
// data/sync/sync_manager.dart

/// 登录后调用：推送积压 → 拉取并替换 user.db
Future<void> onLogin({
  void Function(double progress)? onProgress,
}) async {
  await pushNow();
  final info = await _api!.fetchUserPullInfo();
  await _updateManager!.downloadAndReplace(
    type: 'user',
    url: info.downloadUrl,
    expectedChecksum: info.checksum,
    newVersion: info.version,
    onProgress: onProgress,  // ← 新增，透传
  );
}

/// 手动强制拉取（关于页用）
Future<void> forcePull({
  void Function(double progress)? onProgress,
}) async {
  _ensureInitialized();
  final info = await _api!.fetchUserPullInfo();
  await _updateManager!.downloadAndReplace(
    type: 'user',
    url: info.downloadUrl,
    expectedChecksum: info.checksum,
    newVersion: info.version,
    onProgress: onProgress,  // ← 新增，透传
  );
}
```

### 2.2 AuthRepository —— 改为 await，不阻塞

```dart
// domain/auth_repository.dart

Future<LoginResult> login(LoginRequest request) async {
  final result = await _api.login(request);
  // 登录后同步拉取，由 UI 层控制进度弹窗
  // 不再 unawaited
  return result;
}
```

登录的进度弹窗由 `login_page.dart`（或调用 `AuthRepository.login()` 的地方）控制：先弹窗 → 调 login → 成功后调 `SyncManager().onLogin(onProgress: ...)` → 完成后关弹窗 → 进首页。

### 2.3 AboutPage —— 改为 StatefulWidget，加同步按钮

```dart
// pages/profile/about_page.dart

class AboutPage extends StatefulWidget {
  const AboutPage({super.key});
  @override
  State<AboutPage> createState() => _AboutPageState();
}

class _AboutPageState extends State<AboutPage> {
  String _lastSyncTime = '从未同步';
  bool _syncing = false;

  Future<void> _onSync() async {
    setState(() => _syncing = true);
    try {
      // 弹进度窗
      showSyncProgressDialog(context, (onProgress) async {
        await SyncManager().forcePull(onProgress: onProgress);
      });
      // 同步完成后更新上次同步时间
      setState(() {
        _lastSyncTime = '刚刚';
        _syncing = false;
      });
    } catch (e) {
      setState(() => _syncing = false);
      // 弹窗内已显示失败状态
    }
  }
  // ...
}
```

## 四、状态转换

```
用户操作 → 弹窗（进度条 + "请不要退出此页面"）
  │
  ├─ 下载+校验成功 → ✅ 同步完成 → [知道了] → 关弹窗
  │
  └─ 下载/校验失败 → ❌ 同步失败 → 错误信息 → [关闭] → 关弹窗
```

点「知道了」/「关闭」前弹窗不可关闭（和题库更新弹窗一致）。
