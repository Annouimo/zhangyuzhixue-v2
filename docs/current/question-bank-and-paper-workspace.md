# 题库与组卷重组方案

## 决策摘要

学生端将题库浏览、智能组卷和自主选题收敛为同一个“题库与选题”工作流。
三个旧入口在迁移期间保持兼容，但不再分别演进筛选界面。

- 用户先选择内容范围，再查看匹配结果。
- 匹配结果可用于单题浏览、直接练习、智能抽取或手动加入试卷。
- 智能抽取和手动挑题是同一试卷篮的两种操作，可以混合使用。
- 试卷编辑、试卷管理、练习和 PDF 输出继续作为独立后续环节。
- 筛选默认从空范围开始添加，不再用“默认全选后排除”的方式表达不限。

## 套卷定义

套卷不建立独立数据模型。题库中的套卷是题目字段产生的虚拟集合：

```text
套卷键 = year + exam_type + region
套卷题序 = number
```

本地 `assets.db` 在 2026-07-28 的核查结果：

- 共 798 道题，题号缺失数为 0。
- 共 38 个套卷组合，每套 21 题。
- 各套题号均为 1 至 21，套内没有重复题号。

因此套卷目录、整套练习和整套生成试卷均可由动态查询完成。用户确认生成的试卷仍保存固定题目 ID 和顺序，避免题库更新改变历史试卷。

## 目标流程

```text
选择内容范围
按套卷 / 按专题 / 按知识卡片 / 当前错题 / 常用范围 / 搜索
        ↓
查看匹配结果和题型统计
        ↓
单题浏览 / 开始练习 / 智能抽取 / 手动加入试卷
        ↓
试卷篮（允许智能补足）
        ↓
编辑试卷
        ↓
保存 / 练习 / PDF
```

## 筛选语义

每个维度必须区分以下状态：

1. `unset`：必选范围尚未设置，不执行全库查询。
2. `unrestricted`：可选维度不限，不参与查询约束。
3. `selected`：只使用明确选择的值。

同一维度内为“或”，不同维度之间为“且”。树形范围选择器支持展开、全选和半选；展开目录不得隐式选择目录。

## 常用范围

取消“学习偏好”作为首次登录必填系统。现有 `preference_filter` 表和同步协议暂时保留，并在用户界面改称“常用范围”：

- 用户可保存当前选题范围并命名。
- 常用范围只作为快捷入口，不作为推荐算法的必要输入。
- 推荐练习主要依据作答记录、近期错题和薄弱概念自动产生。
- 新用户无历史数据时使用基础探索题，不要求先填写偏好。

## 错题和收藏

第一阶段只实现错题范围。现有 `submission_detail` 已记录 `question_id`、`attempt_number`、`is_correct` 和时间，无需新增错题表。

- 当前错题以每道题最新一次有效作答错误为准。
- 最新一次作答正确后进入已订正，不再属于当前错题。
- 当前错题可以直接练习、智能抽取或加入试卷。

单题收藏不在近期范围内。当前系统只有试卷收藏；未来若重新评估单题收藏，需要新增本地表、服务端关系、同步支持和题目卡片操作，不与错题功能绑定交付。

## 分阶段实施

### 阶段一：概念和入口收敛

- 登录成功后直接进入主界面，不再强制填写学习偏好。
- 将“学习偏好”界面文案改为“常用范围”。
- 保留旧路由和数据协议，避免已有数据失效。
- 更新产品文档与现有组件测试。

### 阶段二：统一范围选择

- 新建范围状态模型，表达 `unset / unrestricted / selected`。
- 从现有 `FilterPanel` 拆出目录树、已选摘要和高级筛选组件。
- 实现虚拟套卷聚合查询和按题号排序。
- 题库首页默认展示按套卷、按专题、按知识卡片和常用范围。

### 阶段三：统一选题工作台

- 题目结果支持普通浏览和批量选择模式。
- 引入跨范围保留的试卷篮。
- 智能抽取、手动选择和智能补足共享同一个试卷草稿。
- 旧智能组卷和自主选题路由转发到统一工作台，并保留深链兼容。

### 阶段四：错题范围

- 增加“当前错题”和“已订正”查询。
- 将错题作为统一选题工作台的一种内容范围。
- 支持错题重练、加入试卷和智能抽取。

### 阶段五：清理与增强

- 删除不再使用的偏好欢迎流程和重复筛选页面。
- 单题收藏保持不实施，除非后续产品决策重新纳入。
- 清理旧文案、旧测试和已废弃路由。

## 验收原则

- 用户进入题库时不会看到所有精细选项全部选中。
- 未选择内容范围时不会自动查询全部题库。
- 套卷无需持久化模型即可稳定得到 21 道有序题目。
- 同一组选题结果可以浏览、练习、智能抽取和手动组卷。
- 已有常用范围、历史试卷和同步数据继续可用。
- 推荐功能在没有常用范围时仍然正常工作。

## 当前实施进度

截至 2026-07-28，已完成：

- 登录偏好阻断移除及“常用范围”概念迁移。
- 虚拟套卷目录、完整套卷范围和数值题号排序。
- 题库浏览、手动选题、智能选题、智能补足和试卷篮合并。
- 练习首页与试卷管理入口收敛，旧组卷路由保留兼容。
- 概念树渐进展开、整组选取和半选状态。
- 基于最新有效作答的“当前错题/已订正”范围。
- 题库首页常用范围快捷恢复。
- 旧 `/exam/auto` 与 `/exam/pick` 深链重定向到统一工作台。
- 旧智能组卷和自主选题页面缩减为兼容转发层，重复的筛选、积分和生成逻辑已移除。
- `FilterPanel` 的折叠分区、选项组和范围说明已拆为无状态展示组件，筛选状态与公开接口保持兼容。
- `FilterState` 已独立为可复用状态模型，筛选摘要和未选提示也已从主面板分离。
- 手选试卷在扣积分前进入草稿确认，可修改标题、移除题目、拖动排序并查看题型统计；确认后的题序按草稿顺序持久化。
- 智能选题和智能补足会先生成具体候选草稿，保留手选题并按题型容量与目标难度补足；用户确认草稿后才扣积分保存。

统一工作台的核心重组流程已完成。后续增强可聚焦草稿内替换单题、分题型调整目标数量及更细致的智能选题策略；单题收藏不在近期范围内。
