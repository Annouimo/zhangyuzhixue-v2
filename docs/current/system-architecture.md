# 系统架构

最后核验：2026-07-28

系统由学生端 Flutter、Django 服务端、静态官网和离线数据包组成。

## 学生端

`flutter_app` 使用 Repository、DAO、API 三层访问数据。题库与讲义可从预置或更新后的 SQLite 数据包读取；用户学习数据保存在本地用户数据库，并通过同步队列上传。

## 服务端

- `accounts`：认证、学生资料、账号生命周期。
- `qbank`：题目、解析步骤、知识卡片和概念标签。
- `courses`：讲义系列与讲义内容。
- `interactions`：作答记录、反馈、组卷和同步。
- `system`：版本、积分、成就、公告和管理工具。

服务端不再包含教师角色、班级关系或作业发布模型。

## 官网

`landing` 是静态站点，不承载业务后台。生产 Django 仅部署 `server/`；官网有独立发布流程。
