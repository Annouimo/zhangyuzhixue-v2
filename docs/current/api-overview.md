# API 概览

最后核验：2026-07-28

API 基础路径为 `/api/v1/`，详细请求和响应以服务端 OpenAPI schema 为准。

| 领域 | 主要能力 |
|---|---|
| 认证与用户 | 登录、注册、刷新、退出、资料、头像、密码和账号删除 |
| 内容 | 讲义系列、章节目录、Markdown 内容、视频目录、视频详情与讲义关联 |
| 同步 | 批量推送学习数据、拉取用户数据库、数据包版本检查 |
| 试卷 | 自定义组卷、公开、点赞、收藏和 PDF |
| 系统 | 版本、公告、积分、等级和成就 |

不存在 `/api/v1/teacher/`、班级 API 或作业 API。讲义接口要求认证，但不按班级过滤。
