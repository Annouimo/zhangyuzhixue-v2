# 产品边界

最后核验：2026-07-28

章鱼智学是面向高中生的高考数学学习工具。当前产品围绕题目练习、逐步解析、个性化推荐、组卷、讲义、学习记录、统计、积分与离线同步展开。

学生端按“推荐、组卷、复盘、内容、我的”组织已有能力，并以本地单题连续推荐作为核心体验。第一版实施范围和延期事项见 [学生端体验重组计划](student-experience-restructure.md)。

## 当前能力

- 按题型和知识维度练习，支持选择、填空和解答题流程。
- 打开推荐后直接进入单题练习，由本地规则穿插新题、近期错题和同知识点新题。
- 查看逐步解析、知识卡片并记录掌握反馈。
- 自动组卷、自主选题、试卷预览和 PDF 输出。
- 在试卷会话中选择计时，并在连续作答过程中查看当前用时。
- 查看公开讲义系列和讲义内容，不按班级或角色授权。
- 按知识点动态查看“数据不足、正在形成、待巩固、基本掌握”状态。
- 保存学习记录、统计、积分、成就和偏好，并与服务端同步。

## 不在当前范围

- 教师 Flutter 客户端和教师 Web。
- 班级、课程授权、教师作业和作业催交。
- 面向学生的课程售卖与课程排期。
- 通用 AI 聊天、社区和排行榜。

`server/courses` 中的 `Course` 表示讲义系列，`Document` 表示一篇讲义。
