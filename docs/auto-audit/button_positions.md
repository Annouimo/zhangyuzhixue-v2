# winnav 按钮坐标表

## 用法

`winnav_click_at(x=<锚点x>, y=<锚点y>, dx=<dx>, dy=<dy>)`

实际点击位置 = 锚点(`x_pct × client_w`, `y_pct × client_h`) + (`dx`, `dy`)

`dx`/`dy` 是客户区像素偏移，不随窗口 resize 变化。
校准新按钮：`winnav_mouse_pos(x_pct, y_pct)` → 记录 `offset_px` → 填入下表。

## 通用锚点

| 锚点 | `(x_pct, y_pct)` | 适用场景 |
|------|:-----------------:|---------|
| 左上角 | (0, 0) | AppBar 返回按钮、Dialog 关闭按钮 |
| 左下角 | (0, 1.0) | 底部条左端按钮 |
| 右下角 | (1.0, 1.0) | 底部条右端按钮 |
| 右上角 | (1.0, 0) | 页面右上角操作按钮 |
| 中心 | (0.5, 0.5) | 弹窗/居中按钮 |

## 注意

- 行内文字（"待办作业""讲义"等）本身在 `InkWell` 内可点击，不必点右侧 `>` Icon
- `winnav_click(text="←")` 会匹配 AppBar 返回按钮导致误导航，底部翻页栏请用 `y_range` 或 `click_at`
