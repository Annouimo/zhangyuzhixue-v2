## 每种类型完成后的人工补充检查

| 类型 | 人工重点 |
|------|---------|
| A | 模型字段值正确性（范围/default/choices）、API 端点返回值链追踪 |
| B | Repository 方法签名 vs 设计稿逐方法比对、数据流完整（checkAll 返回值消费） |
| C | HTML ↔ Flutter 元素感官比对（颜色/间距/字体）、异常处理充分性、底栏导航是否一致。注意：引擎 2B 只覆盖 7 个关键页面，剩余页面（recommend/profile_edit/register/achievement/level_detail/points 等）需要人工做元素清单比对 |
| D | 功能边界是否超出学生端范围、API 权限是否正确、API 响应字段 vs 设计文档表是否一致 |
| E | 服务器端 systemctl/crontab 现场验证（引擎无法远程检查） |
| F | 数据行数核对、字段内容随机抽样 3 条 |
| G | 设计文档状态标记是否过时、备份方案完整性 |
