## 每种类型完成后的人工补充检查

| 类型 | 人工重点 |
|------|---------|
| A | 模型字段值正确性、API 端点返回值链追踪 |
| B | Repository 方法签名 vs 设计稿逐方法比对、数据流完整 |
| C | HTML ↔ Flutter 元素感官比对、异常处理充分性 |
| D | 功能边界是否超出学生端范围、API 权限是否正确 |
| E | 服务器端 systemctl/crontab 现场验证 |
| F | 数据行数核对、字段内容随机抽样 3 条 |
| G | 设计文档状态标记是否过时、备份方案完整性 |
| R | 纯 NDJSON 断言，仅需确认 SUSPICIOUS 项。~30s |
| RV | 自动走查 → NDJSON → Vision。查看截图确认误判。~5min |
