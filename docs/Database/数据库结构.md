### 📐 核心模型结构（字段与关系终稿）

#### 1. 题库 App (`question_bank`)

**① BaseQuestion (题目主表)**
- **字段**：`id`, `year` (年份), `exam_type` (考试类型), `region` (地区), `number` (题号), `question_type` (选择/填空/解答), `difficulty` (难度, Decimal, 0-10), `calculation` (计算量, Decimal), `stem` (题干, 含图片URL), `default_score` (参考分值)
- **关系**：与 `ConceptTag` 多对多；与 `SolutionMethod` 一对多。
- **关键点**：所有题型的公共字段汇聚于此。

**② ChoiceExt / FillExt / SolutionExt (题型扩展表)**
- **继承方式**：均使用 `OneToOneField` 指向 `BaseQuestion`。
- **ChoiceExt独有**：`options` (JSONField, 存 `{"A":"...", "B":"..."}`)。
- **FillExt独有**：无特殊字段，仅占位。
- **SolutionExt独有**：无特殊字段（**小问题干已彻底分离至 `SubQuestion` 表**）。

**③ SubQuestion (小题树形表)**
- **字段**：`id`, `question` (外键指向 BaseQuestion), `parent` (外键指向自身, 允许为空), `stem` (题干)。
- **作用**：支持无限层级嵌套（如 2 -> 2(1) -> 2(1)(i)）。

**④ SolutionMethod (解法表)**
- **字段**：`id`, `sub_question` (外键指向 SubQuestion), `method_name` (如“代数法”), `source` (AI生成/汇编PDF)。
- **作用**：支持一题多解。

**⑤ SolutionStep (解析步骤表)**
- **字段**：`id`, `method` (外键指向 SolutionMethod), `step_number` (整数), `content` (TextField, 存文字+LaTeX)。
- **关系**：与 `KnowledgeCard` 多对多。

**⑥ KnowledgeCard (知识卡片表)**
- **字段**：`id`, `title`, `content` (卡片详细内容)。
- **特点**：全局独立复用。

**⑦ ConceptTag (概念标签树)**
- **字段**：`id`, `name`, `parent` (外键指向自身, 允许为空)。
- **特点**：通过自关联实现“集合 -> 并集”的父子层级。

---

#### 2. 课程中心 App (`course_center`)

**① Course (课程)**
- **字段**：`id`, `name`, `description`。

**② ClassGroup (班级)**
- **字段**：`id`, `name`。
- **注意**：避开 Python 保留字 `Class`。

**③ ClassCourse (班级-课程绑定)**
- **字段**：`id`, `class_group` (外键), `course` (外键), `start_date`, `end_date`。
- **作用**：多对多中间表，存课程在该班级的有效期。

**④ Lecture (讲义)**
- **字段**：`id`, `title`, `file_url`, `course` (外键指向 Course)。
- **关系**：一份讲义属于一门课（若需复用，改为多对多）。

**⑤ Assignment (作业)**
- **字段**：`id`, `title`, `description`。
- **关系**：与 `Course` 多对多。

**⑥ AssignmentQuestion (作业-题目中间表)**
- **字段**：`id`, `assignment` (外键), `question` (外键指向 BaseQuestion), `order` (整数)。
- **作用**：定义题目在作业中的顺序。

**⑦ ClassCourseAssignment (作业发布表) —— 核心枢纽**
- **字段**：`id`, `class_course` (外键指向 ClassCourse), `assignment` (外键), `publish_at` (发布时间), `deadline` (截止时间), `is_active` (布尔)。
- **作用**：决定“哪个班级的哪门课，在什么时间段内能看到并提交哪份作业”。

---

#### 3. 用户管理 App (`user_management`)

**① Student (学生)**
- **字段**：`id`, `user` (关联 Django 内置 User), `class_group` (外键指向 ClassGroup, **允许为空**), `points` (积分)。
- **流程**：注册时班级为空，管理员手动拉入。

---

#### 4. 交互 App (`learning_interaction`)

**① StudentSubmission (提交记录主表)**
- **字段**：`id`, `student` (外键), `class_course_assignment` (外键指向发布表), `submitted_at` (自动记录时间)。

**② SubmissionDetail (提交明细) —— 关键修正**
- **字段**：`id`, `submission` (外键指向主表), `question` (**直接外键指向 BaseQuestion**), `answer_text` (学生答案), `is_correct` (布尔, 可空)。
- **作用**：**直接关联题目本身**，用于实现跨作业“已做”标记。

**③ StepFeedback (步骤反馈)**
- **字段**：`id`, `submission_detail` (外键指向明细), `step` (外键指向 SolutionStep), `status` (三选一：全对/流程对/计算错)。

**④ CardFeedback (卡片反馈)**
- **字段**：`id`, `submission_detail` (外键), `card` (外键指向 KnowledgeCard), `status` (三选一：完全掌握/了解/不了解)。

**⑤ QuestionRating (题目评分)**
- **字段**：`id`, `student` (外键), `question` (外键指向 BaseQuestion), `difficulty_score`, `calculation_score`, `elegance_score`。
- **约束**：`unique_together = ('student', 'question')`，允许覆盖。

### 🔑 权限查询路径（快速回顾）

当学生登录后，系统按此链路获取可见内容：

1.  `Student` -> `class_group` (找到班级)
2.  `ClassGroup` -> `ClassCourse` (多对多，找到该班级绑定的所有课程)
3.  `ClassCourse` -> `ClassCourseAssignment` (找到该课程下已发布的作业)
4.  `Assignment` -> `AssignmentQuestion` (找到作业里的题目列表)

**讲义**：直接根据 `Course` 过滤，或通过多对多关系获取。

**已做标记**：查询 `SubmissionDetail` 表，过滤条件 `student=当前学生` 且 `question=当前题目ID`，有记录即已做。

### 💎 终稿特性总结

- **灵活性**：支持概念标签无限级树形结构、题目无限级小题嵌套、一题多解。
- **可扩展性**：题型扩展表可以随时增加字段，互不影响。
- **性能优化**：核心查询最多只关联 3-4 张表，无冗余 JSON 大字段干扰排序和过滤。
- **业务闭环**：从作业发布、学生作答、步骤反馈、卡片反馈到题目评分，全流程数据可追溯。
