## 一、解题模式

按题型拆分为三个独立 HTML 原型页面：`solve-choice.html`（选择题）、`solve-fill.html`（填空题）、`solve-solve.html`（解答题）。选择/填空共用冷却→提交/查看→结果→完成横幅模式，Flutter 中应抽象为共享 Widget。评分独立到 `solve-rate.html`，三题型共享入口，允许复访修改。

**Widget 复用说明：** 选填题的流程高度相似（冷却按钮等待 → 提交/查看 → 展示结果 → 🎉 已完成 → [下一题] [⭐ 评分]），Flutter 实现时应抽取 `SolveBaseWidget` 或 `SolveFlowWidget` 处理共同流程，选择/填空分别继承/组合。解答题的步骤卡（冷却箭头 → 展开 → 反馈按钮）单独抽取 `StepCardWidget`。

### 完整交互序列

```
选填题：
  [题目显示]
  ↓
  10s 冷却 → 按钮禁用 + 小字倒计时
  ↓
  按钮恢复可用 → 用户提交/查看答案
  ↓
  自动展示结果（正确/错误 + 解析）
  ↓
  🎉 已完成 横幅 + [下一题 →] [⭐ 评分]
  ↓
  [下一题] → 继续
  [⭐ 评分] → solve-rate.html

解答题（N 步）：
  [当前步卡片显示]
  ↓
  5s 冷却 → 箭头按钮禁用 + 小字倒计时
  ↓
  箭头恢复可用 → 用户点击箭头 ▶
  ↓
  解析内容展开 → 反馈按钮出现
  ↓
  用户选择反馈 → 下一步卡片显示（重复直到最后一步）
  ↓
  全部完成 → 🎉 已完成 横幅 + [下一题 →] [⭐ 评分]
```

### 防刷倒计时交互规则

- **计时起点**：题目显示（选填）/ 当前步卡片显示（解答），二者统一
- **冷却时长**：选填 10 秒，解答每步 5 秒（通过 assets.db → `system_config` 表的 `solve_cooldown_choice` / `solve_cooldown_step` 配置）
- **禁用对象**：选填题→「提交/查看」按钮；解答题→箭头按钮
- **禁用形态**：按钮 `opacity: 0.4; cursor: not-allowed`；按钮下方显示 `⏳ 还剩 N 秒可提交`
- **恢复时机**：冷却到时，按钮恢复可用，倒计时文字消失
- **重置时机**：进入下一状态时（下一题 / 下一步卡片显示）
- **无额外弹窗/Toast 提示**（视觉禁用 + 小字足够，不干扰读题）

### 知识卡片交互

- 步骤标题旁的知识标签可点击
- 点击弹出知识卡片弹层（LaTeX 渲染）
- 点击弹层外部关闭

### 评分交互

评分已从解题页独立到 `solve-rate.html`，三题型共享。
- 用户从完成横幅点击「⭐ 评分」进入评分页
- 评分页展示 3 组 10 星：**难度**、**计算量**、**优雅度**
- 难度和计算量显示算法分对比；优雅度无算法分
- 允许复访修改（不是一次性评分）
- 未来可从其他入口进入（历史记录、错题本、收藏夹）

### 复访重建

第二次及更多次进入解题页时，不从零开始，而是从 user.db 读取历史记录重建解题状态。

**判断逻辑：**

| 类型 | 判定条件 |
|------|---------|
| 首次 | `submission_detail` 中无该 `question_id` 的记录 |
| 复访 | 有记录 |

**数据源（4 张 user.db 表）：**

| 表 | 用于重建什么 |
|----|------------|
| `submission_detail` | 选填是否已提交、对错 |
| `step_feedback` | 每步的 feedbackGiven + feedbackType |
| `card_feedback` | 知识卡片掌握度（仅状态展示） |
| `question_rating` | 是否已评分 |

**重建流程：**

```
solve 页 init
  ↓
ProgressRepository.getPreviousState(qid)
  ├── null  → 首次 → 正常冷却+交互
  └── PreviousSolveState → reconstructFromState()
       ├── completedSubQs  ← step_feedback 推算
       ├── currentMethod   ← 取有最新 step_feedback 的方法
       ├── stepState       ← 每条 step_feedback
       ├── 未做的下一步    ← 无 step_feedback 的最前步
       ├── 评分区          ← isRated=true 显示已有评分
       └── 冷却计时器不启动（复访不需要防刷）
```

**首次 vs 复访 UI 差异：**

| 元素 | 首次 | 复访-已完成 | 复访-部分完成 |
|------|------|------------|-------------|
| 选择题选项 | 可选+可提交 | 不可选，结果区直接展示 | 同已完成 |
| 填空题按钮 | 10s冷却→可点 | 直接展示答案 | 直接展示答案 |
| 解答题箭头 | 禁用→冷却→可点 | 已完成的步：箭头隐藏，内容展开 | 同上；未完成的步：正常冷却→可点 |
| 反馈按钮 | 可交互 | 已选中的选中态 | 同上；当前步正常 |
| 冷却计时器 | 全部启动 | 不启动 | 只在"当前待继续步"启动 |
| done-section | 全部完成时显示 | 直接显示 | 不显示 |
| 评分 | 独立页 solve-rate | 可修改 | 可修改 |

## 二、讲义

`lecture_courses.html` → `lecture_chapters.html` → `lecture_content.html`

- 三级下钻：课程列表 → 章节目录 → 正文
- 数据流：
  - 服务端 `Document.md_content` 存储含分隔符的原始 markdown
  - 客户端 `lecture_content` 表镜像存储同一份 raw markdown（不解析）
  - 渲染时调用 `parseMdContent()` 解析为结构化 `pages[].blocks[]`（纯内存，不持久化）
  - 分隔符：`<!-- pagebreak -->`（分页）、`<!-- reveal -->`（同页内展开块分割）
- 底部固定翻页栏：
  - ◀/▶ 按钮，智能决定展开或翻页
  - 页码格式：「第 X / Y 页 · 展开 A / B」
  - ◀：有已展开块则收回，无则翻上一页
  - ▶：有未展开块则展开，无则翻下一页
  - 全部展开/收回后按钮切换为翻页模式（蓝底白字 `→`/`←` 样式变化）
- REVEAL 逐段展开机制：`parseMdContent()` 解析后，每页分为 blocks[0..N]，blocks[0] 默认可见，blocks[1..N] 初始隐藏，逐步点击展开
- 内容区用 `MdLatexBody` 渲染 Markdown + LaTeX
- 讲义中出现的知识标签可点击，弹出知识卡片弹层（复用解题模式的弹层）
- 键盘快捷键支持（低优先级）：← 收回/上一页，→ 展开/下一页
- 路由 page 参数：`/lecture/content?id=1&page=3`

## 三、组卷系统

### 页面

| 页面 | 路径 | 说明 |
|------|------|------|
| 智能组卷 | `paper_auto.html` | 筛选 + 题型 stepper + 难度调优 |
| 自主选题 | `paper_pick.html` | 筛选 + 逐题勾选，底部固定条 |
| 预览（自己） | `paper_quicklook.html` | 公开开关 + 删除 |
| 预览（他人） | `paper_quicklook_other.html` | 点赞 + 收藏 |
| 我的组卷 | `paper_history.html` | 列表 + 公开/私密开关 |
| 发现组卷 | `paper_explore.html` | 4种排序 + 点赞 + 收藏 |
| 我的收藏 | `paper_favorites.html` | 收藏的他人试卷 |
| 快对答案 | `answer_sheet.html` | 答案速览列表 |

### 筛选模块交互

筛选模块在 `paper_auto`、`paper_pick`、`recommend` 三页共用一套交互：
- 学科、难度（5段滑块）、题型（选/填/解）、分值范围
- 筛选结果实时更新计数
- 过滤条件可保存为预设（偏好推荐）
- 自主选题跨筛选保留：独立维护 `Set<int> selectedIds`

### 难度调优（智能组卷）

- 题型默认值（选10填5解6）及高考参考难度从 DB 读取
- 难度调优上下限 = 当前筛选池实际极值，动态变化
- 5段分段标签方案见 [设计系统.md](设计系统.md)

### 公开/点赞/收藏

- 自己的试卷可开关公开/私密
- 他人的试卷可点赞、收藏
- 点赞、收藏需服务端接口（多人操作）

## 五、学习统计

`statistics.html` — 概览卡片 + 全局时间范围切换 + 4 个图表卡片。

### 时间范围切换

5 个 pill 按钮全局切换，影响除概览外的所有图表数据：

| 选项 | 值 | 每日学习显示模式 |
|------|-----|----------------|
| 近一周 | 7天 | 水平条形图（天/格） |
| 近一月 | 30天 | 7行周历（天/格） |
| 近三月 | 90天 | 7行周历（天/格） |
| 近一年 | 365天 | 周/格贡献图 |
| 全部 | 动态 | 月/格 |

### 自适应粒度规则

```
天数 ≤ 14   → 水平条形图
15 ≤ 天数 ≤ 90  → 7行周历
91 ≤ 天数 ≤ 730 → 周/格贡献图
天数 > 730      → 月/格
```

染色 0~3 级按当期内最大值归一化。

### 图表卡片

4 个图表卡片，每个卡片有独立的 data-db 数据源和渲染方式（详见 `html/statistics.html`）：

| 卡片 | 图表类型 | 数据源 (data-db) | 渲染方式 |
|------|---------|-----------------|---------|
| 做题热力图 | 4种自适应模式 | `stats.getDailyRecords` | div + CSS 染色 (lv0~lv3) + data-db-loop |
| 正确率趋势 | 折线图 | `stats.getAccuracyTrend` | SVG polyline + circle 描点 + 网格线 |
| 积分累计趋势 | 折线图 | `stats.getPointsTrend` | SVG polyline + 动态 Y 轴刻度 |
| 题型分布 | 环形图 | `stats.getDistribution` | conic-gradient + 图例 |

自适应规则见上方。热力图染色 0~3 级按当期内最大值归一化，缺失日期自动显示为 lv0。

## 六、退出页面评价

弹出时机：返回按钮 20%概率（`solve`/`paper_quicklook`/`lecture_content`），同页 24h 冷却，停留>30s 触发（概率/停留阈值/奖励积分通过 assets.db 的 `system_config` 表配置，冷却时长硬编码在 AppPrefs 中）。

异常处理：提交过程（冷却写入 → SyncApi 入队 → 积分赠送）任一步骤失败时，不设冷却（用户可下次重试），弹出错误提示 SnackBar。

弹层内容：5 级表情评分 + 文字反馈
- 提交评价可获得赠送积分
- 冷却机制：存本地 SharedPreferences
